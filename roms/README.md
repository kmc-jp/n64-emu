## Third-party ROMs

This folder contains Nintendo 64 ROM images used for development, demos, and
tests. They are **not** part of the n64-emu MIT license; keep each author's
terms.

- `zophar/` — Downloaded from https://www.zophar.net/pdroms/n64.html
- `dillonb-n64-tests/` — Pre-built CPU test ROMs from
  [Dillonb/n64-tests](https://github.com/Dillonb/n64-tests). Upstream does not
  publish a license; included only with personal permission for use with this
  emulator. See that directory's README for details.

See the readme / text files next to each ROM for authorship details.
